# Elevance Internship Tasks

## Overview

This repository contains all AI and Machine Learning projects completed during the Elevance Internship.

The projects focus on chatbot development, Natural Language Processing (NLP), AI assistants, sentiment analysis, multilingual communication, and domain-specific chatbot systems.
