# Multilingual AI Chatbot

## Overview

This project is a multilingual chatbot developed using Streamlit. It supports multiple languages and can automatically detect the user's language, translate queries, maintain conversation history, and provide context-aware responses.

## Features

* Automatic Language Detection
* Manual Language Switching
* English Support
* Hindi Support
* Spanish Support
* German Support
* French Support
* Portuguese Support
* Conversation History
* Context Retention
* Mixed Language Queries
* Streamlit User Interface

## Technologies Used

* Python
* Streamlit
* LangDetect
* Deep Translator

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```

## Example Queries

* What is Machine Learning?
* Machine Learning kya hai?
* ¿Qué es Machine Learning?
* Was ist Machine Learning?
* O que é Machine Learning?
