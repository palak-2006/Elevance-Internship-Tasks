# Task 4 - Arxiv Expert Chatbot

## Overview

This project is an Arxiv Expert Chatbot built using Streamlit. It allows users to search and explore Computer Science research papers from the arXiv dataset.

## Features

* Search research papers by keywords
* View paper titles and abstracts
* Retrieve relevant papers using NLP techniques
* Interactive Streamlit interface
* Research paper exploration and summarization

## Project Structure

Task-4-Arxiv-Expert-Chatbot/

* app.py
* chatbot.py
* arxiv_loader.py
* requirements.txt
* README.md
* dataset/

## Dataset

Dataset is not included in this repository because the original arXiv dataset file is larger than GitHub's file size limit.

Download the dataset from:

https://www.kaggle.com/datasets/Cornell-University/arxiv

Place the file here:

dataset/arxiv-metadata-oai-snapshot.json

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Application

streamlit run app.py

* Python
