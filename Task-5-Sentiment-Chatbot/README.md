# Task 5 - Sentiment Analysis Chatbot

## Overview

This project is a Streamlit-based chatbot that performs sentiment analysis on user messages. It detects whether the sentiment is Positive, Negative, or Neutral and generates an appropriate response.

## Features

* Sentiment Detection using VaderSentiment
* Positive, Negative, and Neutral Classification
* Emotion-aware Responses
* Interactive Streamlit Interface

## Technologies Used

* Python
* Streamlit
* VaderSentiment

## Installation

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```

## Example Inputs

Positive:
I love this product!

Negative:
This service is terrible.

Neutral:
What are your working hours?

## Outcome

The chatbot recognizes user sentiment and responds appropriately, improving user interaction and customer experience.
